# Estudos de Lógica em C# (.NET)

Repositório onde estou guardando os meus primeiros projetos práticos aprendendo C# e lógica de programação do zero.

## O que tem aqui:

* **Calculadora.cs** - Minha primeira calculadora no terminal. Faz as 4 operações básicas e repete enquanto o usuário quiser fazer novas contas.
* **JogoAdivinhacao.cs** - Jogo onde o sistema sorteia um número de 1 a 100 e vai dando dicas se o chute foi mais alto ou mais baixo até acertar.
* **CaixaEletronico.cs** - Simulador simples de banco com consulta de saldo, depósito, saque e Pix, atualizando o saldo a cada operação.

Feito usando C#, .NET 10 e VS Code.
